# Experiment engine

Create 2–26 unique hook text levels or numeric shot-segmentation levels. Each variant has a UUID, A–Z display label, exact changed parameter, factor assignments, frozen base revision, editable composition, render output linkage, and measurement lineage. The pure factorial helper preflights up to 26 combinations; a multi-factor UI is not implemented.

Snapshots are imported manually as binary retained plays / eligible plays for an explicitly stated observation window. Do not import arbitrary summed engagements as binomial successes. Synthetic observations are labeled, tracked separately, and cannot be compared against real observations in one experiment.

The comparison requires all variants measured, at least 100 observations each, and the same preselected 24-hour window. It ranks rates, not raw views, computes conservative Wilson intervals (z=2.24 for two levels; 3.5 for up to 26), and requires interval separation before reporting a supported association. Otherwise it returns insufficient comparable exposure or inconclusive. Calculation inputs and timestamps are preserved.

Organic distribution is observational, and repeated plays may not be independent people. Intervals are exploratory approximations, not a causal result or a repeated-peeking-safe guarantee. Metrics such as Instagram skip rate may be rounded and cannot automatically be substituted for exact binary counts. No retention metric is invented from unavailable API fields. The current engine does not implement bootstrap, hierarchical inference, sequential stopping, randomized distribution, or exposure balancing.

Follow-up creation retains the parent experiment ID and reopens the designer. Recommendations are deterministic evidence summaries; no LLM is allowed to invent a winner.
